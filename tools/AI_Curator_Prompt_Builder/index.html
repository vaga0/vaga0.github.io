📖 使用說明

這是什麼？

這個工具幫你快速產生一段「AI 對話轉互動講義」的指令 (Prompt)。
當你與 AI（ChatGPT、Claude、Gemini 等）完成一段有價值的深度對話後，把這段 Prompt 貼給 AI，它就會自動把整段聊天內容轉化為一份高視覺品質、具備互動元素的單頁 HTML 網頁。

什麼時候用？

  • 你跟 AI 深聊完一個主題，覺得精華內容值得保存
  • 你想把對話整理成可分享、可複習的互動講義
  • 你需要不同風格（淺色/暗色/不同配色）的視覺呈現

三步驟使用

  1. 1組裝 Prompt：在本頁選擇你要的段落、配色風格、追加模組
  2. 2複製貼上：點擊底部「📋 複製」按鈕，回到 AI 對話視窗直接貼上送出
  3. 3取得 HTML：AI 會回覆完整的 HTML 程式碼，將它存成 .html 檔案，雙擊即可在瀏覽器開啟

各區塊說明

  • 核心段落 (1-5)：構成 Prompt 的五大指令區塊，預設全開。若某功能不需要，關掉開關即可排除
  • 配色風格：決定 AI 產出的 HTML 長什麼樣子。6 種風格任選其一
  • 追加模組：額外功能（如 Light/Dark 切換、目錄導航等），勾選後會自動插入 Prompt 適當位置

💡 小提醒

  • 此 Prompt 適用於所有主流 AI 模型，但建議使用能力較強的模型（如 GPT-4o、Claude Sonnet/Opus、Gemini Pro）以獲得最佳 HTML 品質
  • 若 AI 一次無法完整輸出所有程式碼，可以回覆「請繼續」讓它補完
  • 產出的 HTML 可免費發佈至 GitHub Pages、Netlify 或 Vercel
